# 🏙️ Flat Inspector / Gazprom_project

Сервис для автоматической проверки объявлений о продаже и аренде квартир.  
Проект разрабатывается в рамках учебного курса: на вход подаётся ссылка на объявление или скриншот параметров, система проводит «расследование» и выдаёт сводный отчёт о справедливости цены.

**Текущий этап (ДЗ №1):** Написан базовый парсер для сбора данных с сайта [cian.ru](https://www.cian.ru). Парсер собирает структурированные данные (цена, площадь, этаж, координаты), текстовое описание и ссылки на изображения. Данные сохраняются в формате JSONL и версионируются с помощью DVC.

## ✨ Функциональность
На данный момент реализовано:
- ✅ Генерация задач поиска по округам Москвы, количеству комнат и диапазонам цен.
- ✅ Сбор ID объявлений через API Cian (с обходом блокировок через `curl_cffi`).
- ✅ Загрузка детальной страницы объявления и парсинг:
  - структурированные данные: цена, площадь, этажность, адрес, метро, характеристики (тип дома, ремонт, высота потолков и др.);
  - текстовое описание;
  - список ссылок на фотографии.
- ✅ Геокодирование адреса через Nominatim (OSM) для получения координат.
- ✅ Сохранение данных в `data/raw/cian_offers.jsonl` (добавление только новых объявлений по `id`).
- ✅ Версионирование данных через **DVC** (удалённое хранилище — локальная папка).
- ✅ Управление зависимостями через **uv** и `pyproject.toml`.

В планах — скачивание изображений и расширение функционала анализа.
